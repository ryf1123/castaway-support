# Cast Away / 远岸 — Support

Cast Away is an offline focus timer with a quiet fishing experience, developed by Yufan Ren.

## Help and feedback

[Open a support issue](https://github.com/ryf1123/castaway-support/issues/new) or [browse existing questions](https://github.com/ryf1123/castaway-support/issues).

A GitHub account is required to submit an issue. Issues are public: do not include your email, phone number, account credentials, personal records or other sensitive information. If a screenshot helps explain a problem, remove personal information before attaching it.

Please include your app version, iPhone model, iOS version, steps to reproduce the problem and what you expected to happen. The developer responds in the issue thread.

## Quick start

1. Complete the welcome screen and choose a focus duration from 5 to 120 minutes.
2. Tap **Start focus**, or pull downward and release to cast.
3. Let the timer run while you focus. Locking the phone does not pause the session.
4. At the end, review your catches. Ending early releases the current session's catches.

Notifications and sound are optional. You can change notification and Live Activity permissions in iOS Settings. Records are stored locally; deleting the app removes its local data. Reinstalling does not restore records unless a compatible device backup restores them.

# 远岸 — 支持与反馈

远岸是一款结合安静钓鱼体验的离线专注计时应用，由 Yufan Ren 开发。

通过 [GitHub Issues](https://github.com/ryf1123/castaway-support/issues) 提问或报告问题。提交反馈需要 GitHub 账号，开发者会在问题下回复。问题内容公开可见，请勿提交邮箱、手机号、密码、个人记录等敏感信息；上传截图前请移除个人信息。

反馈时请提供应用版本、iPhone 型号、iOS 版本、复现步骤和预期结果。

完成欢迎页后选择 5–120 分钟，点击“开始专注”或下拉松手抛竿。锁屏不会暂停计时。正常完成后查看渔获，提前收杆会放回本次渔获。通知和声音均可自行控制。

记录保存在设备本地；删除应用会移除本地数据，重新安装不会自动恢复记录，除非通过兼容的设备备份还原。
